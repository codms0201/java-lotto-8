# java-lotto-precourse
# 로또 미션

## 기능 요구사항 분석

### 입력
- 로또 구입 금액 (1,000원 단위)
- 당첨 번호 6개 (쉼표로 구분)
- 보너스 번호 1개

### 출력
- 구매한 로또 수량 및 번호 (오름차순 정렬)
- 당첨 통계 (3개~6개 일치)
- 총 수익률 (소수점 둘째 자리 반올림)

### 예외 처리
- 구입 금액이 1,000원 단위가 아닐 경우
- 로또 번호가 1~45 범위를 벗어날 경우
- 로또 번호가 중복될 경우
- 로또 번호가 6개가 아닐 경우
- 보너스 번호가 당첨 번호와 중복될 경우

## 구현할 기능 목록

### 1. 도메인 클래스

#### 1.1 Lotto 클래스
- [x] 로또 번호 6개를 저장한다
- [x] 로또 번호가 6개인지 검증한다
- [x] 로또 번호가 1~45 범위인지 검증한다
- [x] 로또 번호가 중복되지 않는지 검증한다
- [x] 로또 번호를 오름차순으로 정렬하여 반환한다
- [x] 특정 번호가 포함되어 있는지 확인한다
- [x] 다른 로또 번호와 일치하는 개수를 반환한다

#### 1.2 LottoTickets 클래스
- [x] 여러 개의 로또를 관리한다
- [x] 구입 금액으로 로또를 생성한다
- [x] 생성된 로또 목록을 반환한다

#### 1.3 WinningLotto 클래스
- [x] 당첨 번호를 저장한다
- [x] 보너스 번호를 저장한다
- [x] 보너스 번호가 당첨 번호와 중복되지 않는지 검증한다
- [x] 로또와 비교하여 당첨 등수를 반환한다

#### 1.4 Rank 열거형
- [x] 각 등수별 일치 개수, 보너스 일치 여부, 상금을 정의한다
- [x] 일치 개수와 보너스 일치 여부로 등수를 판단한다
- [x] 당첨 여부를 확인한다

#### 1.5 LottoResult 클래스
- [x] 당첨 결과를 저장한다
- [x] 각 등수별 당첨 개수를 반환한다
- [x] 총 수익률을 계산한다

### 2. 입출력 클래스

#### 2.1 InputView 클래스
- [x] 구입 금액을 입력받는다
- [x] 당첨 번호를 입력받는다
- [x] 보너스 번호를 입력받는다

#### 2.2 OutputView 클래스
- [x] 구매한 로또 개수를 출력한다
- [x] 구매한 로또 번호들을 출력한다
- [x] 당첨 통계를 출력한다
- [x] 총 수익률을 출력한다
- [x] 에러 메시지를 출력한다

### 3. 유틸리티 클래스

#### 3.1 InputValidator 클래스
- [x] 구입 금액이 1,000원 단위인지 검증한다
- [x] 구입 금액이 양수인지 검증한다
- [x] 당첨 번호 입력 형식이 올바른지 검증한다
- [x] 보너스 번호 입력 형식이 올바른지 검증한다

#### 3.2 LottoGenerator 클래스
- [x] 랜덤한 로또 번호를 생성한다

### 4. 컨트롤러

#### 4.1 LottoController 클래스
- [x] 전체 로또 게임을 진행한다
- [x] 구입 금액을 입력받아 로또를 발행한다
- [x] 당첨 번호와 보너스 번호를 입력받는다
- [x] 당첨 결과를 계산하고 출력한다
- [x] 예외 발생 시 재입력을 처리한다

### 5. 테스트

#### 5.1 Lotto 클래스 테스트
- [x] 로또 번호가 6개가 아니면 예외가 발생한다
- [x] 로또 번호가 중복되면 예외가 발생한다
- [x] 로또 번호가 범위를 벗어나면 예외가 발생한다
- [x] 일치하는 번호 개수를 정확히 계산한다

#### 5.2 WinningLotto 클래스 테스트
- [x] 보너스 번호가 당첨 번호와 중복되면 예외가 발생한다
- [x] 등수를 정확히 판단한다

#### 5.3 Rank 열거형 테스트
- [x] 일치 개수와 보너스로 정확한 등수를 반환한다
- [x] 당첨되지 않은 경우를 처리한다

#### 5.4 LottoResult 클래스 테스트
- [x] 수익률을 정확히 계산한다

#### 5.5 InputValidator 클래스 테스트
- [x] 잘못된 구입 금액에 대해 예외를 발생시킨다
- [x] 잘못된 번호 입력에 대해 예외를 발생시킨다
